# Learning Notes - Week 01

## Nội dung đã học:
1. **Cấu trúc dự án C++ chuẩn**:
   - `include/`: Chứa file header (`.h`).
   - `src/`: Chứa mã nguồn cài đặt (`.cpp`).
   - `tests/`: Chứa mã kiểm thử unit test.
   - `exercises/`: Chứa các bài tập luyện tập độc lập.
2. **Cú pháp C++ cơ bản**: Khai báo biến, nhập xuất với `std::cin` / `std::cout`, viết hàm và tách module header.
